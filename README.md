# Monitor4
Projeto voltado para simular comportamento de um conexão de uma rede incluindo um servidor e cliente usando a linguagem de Python.

O monitor do sistema deverá implementar um cliente que possa monitorar a performance do sistema operacional 
remoto (do servidor) remotamente: utilização de CPU e memória.  O usuário, através do cliente da aplicação, iniciará a conexão ao servidor, e receberá, de imediato, uma mensagem 
no seguinte formato “<HORARIO>: CONECTADO!!” e um Menu com os monitores disponíveis e sintaxe de uso (no 
diagrama, MSG1).
